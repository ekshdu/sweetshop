# Учет заказов и логистики кондитерской

**Информационная система для автоматизации приема заказов, складского учета, производства и доставки кондитерской**

---

## Концепция и проблема

### Какую боль решает продукт

| Проблема | Следствие |
|---|---|
| **Ручной учет заказов** в бумажных тетрадях, календарях и электронных таблицах | Можно потерять заказ или упустить его детали |
| **Ручной расчет себестоимости** | Замедляется ценообразование, стоимость сырья меняется со временем, покупатель может получить ложные сведения о цене |
| **Ручной учет складского сырья** | Влияние человеческого фактора, отсутствие поставок в необходимое время |
| **Логистика доставки вручную**: распределение заказов и маршруты - по телефону и в мессенджерах | Сложно оценить загрузку курьера, рассчитать время и стоимость доставки, быстро отреагировать на задержку или порчу хрупкого изделия в пути |

### Для кого создается продукт

| Роль | Чем занимается |
|---|---|
| **Клиент** | Заказывает необходимое кондитерское изделие |
| **Кондитер** | Выполняет заказы, поставленные на текущий день |
| **Курьер** | Доставляет заказ из точки кондитерской до точки доставки |
| **Администратор и владелец** | Следит за остатками сырья и отслеживает сроки заказов |

## Основной функционал

Ключевые функции первой версии:

### Клиент
- [x] Регистрация и авторизация
- [x] Электронный каталог изделий с фильтрацией по цене, весу и типу
- [x] Конструктор индивидуального торта (вес, начинка, декор, срочность) с автоматическим расчетом цены
- [x] Оформление и онлайн-оплата заказа (оплата в режиме эмуляции) с выбором даты, временного слота и способа получения
- [x] Личный кабинет: история заказов и актуальный статус
- [x] Отзывы о выполненном заказе
- [x] Расчет стоимости и ориентировочного времени доставки по зонам обслуживания

### Кондитер
- [x] Производственный календарь
- [x] База технологических карт
- [x] Автоматическое списание сырья со склада по технологической карте

### Курьер
- [x] Интерфейс курьера: список заказов, адреса, временные слоты, состав, комментарии клиента, способ оплаты
- [x] Изменение статуса доставки
- [x] Фиксация проблем доставки (невозможность доставки, задержка, повреждение изделия)

### Администратор и владелец
- [x] Расчет себестоимости изделия на основе технологической карты и актуальных закупочных цен
- [x] Контроль сроков годности сырья и уведомления о снижении остатков ниже порога
- [x] Автоматическое распределение заказов между курьерами с учетом зон обслуживания и загрузки
- [x] Отслеживание статуса доставки с уведомлениями
- [x] Финансовая аналитика (выручка, себестоимость, прибыль) за день, неделю и месяц
- [x] Аналитика логистики
- [x] Управление учетными записями и ролями сотрудников
